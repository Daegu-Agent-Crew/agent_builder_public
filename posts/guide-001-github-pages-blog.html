GitHub Pages로 블로그 만들기

이미지가 포함된 리포트 글까지 올리는 방법

대구루 · 2026-04-30

블로그를 만들고 싶은데 서버 비용이 부담스러운가? GitHub Pages는 무료다. 공개 저장소만 있으면 된다. 이 블로그도 그렇게 만들었다.

오늘은 GitHub Pages로 블로그를 세팅하고, 캐릭터 이미지가 포함된 리포트 글까지 올리는 전 과정을 정리한다.

GitHub Pages가 뭔가

GitHub가 제공하는 무료 정적 웹사이트 호스팅이다. 저장소에 HTML 파일을 올리면 바로 웹사이트가 된다.

  • 무료 (공개 저장소 기준)
  • 도메인: username.github.io/repo-name 형식
  • 배포: main 브랜치에 push하면 자동 반영
  • Jekyll(마크다운 → HTML 변환)도 지원하지만, 순수 HTML도 완벽하게 동작
이 블로그처럼 HTML + CSS + JS만으로 만들면 빌드 과정 없이 push하는 즉시 반영된다.

전체 구조 한눈에 보기

블로그의 파일 구조는 이렇다.

my-blog/
├── .nojekyll          ← Jekyll 비활성화 (순수 HTML 사용 시 필요)
├── index.html         ← 메인 페이지
├── style.css          ← 전체 스타일
├── script.js          ← 햄버거 메뉴 등 JS
├── assets/
│   ├── character/     ← 캐릭터 이미지
│   └── post-thumb.png ← 포스트 썸네일/인포그래픽
└── posts/
    └── guide-001.html ← 개별 포스트

핵심은 단순하다. index.html이 목록, posts/ 안의 html 파일들이 개별 포스트다.

Step 1 — 저장소 만들기

GitHub에서 새 저장소를 만든다. 이름은 자유롭게 정한다.

gh repo create my-blog --public
cd my-blog
git init
git remote add origin https://github.com/username/my-blog.git

또는 GitHub 웹에서 New repository 버튼을 눌러도 된다. Public으로 설정해야 무료 Pages가 활성화된다.

Step 2 — 기본 파일 만들기

먼저 .nojekyll 파일을 만든다. 이게 없으면 GitHub가 Jekyll로 빌드하려고 시도한다. 순수 HTML 사이트라면 이 파일이 필요하다.

touch .nojekyll

그다음 index.html을 만든다. 최소 구조는 이렇다.

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>내 블로그</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>안녕하세요</h1>
  <script src="script.js"></script>
</body>
</html>

Step 3 — GitHub Pages 활성화

저장소 설정에서 Pages를 켠다.

  1. GitHub 저장소 → Settings 탭
  2. 좌측 메뉴 → Pages
  3. Source → Deploy from a branch 선택
  4. Branch → main, 폴더 → / (root)
  5. Save

또는 GitHub CLI로 한 번에 할 수 있다.

gh api repos/username/my-blog/pages \
  --method POST \
  -f build_type=legacy \
  -f source='{"branch":"main","path":"/"}'

활성화 후 1~2분 기다리면 https://username.github.io/my-blog/에서 사이트가 열린다.

Step 4 — 포스트 쓰기

posts/ 폴더에 HTML 파일을 추가한다. 파일명은 날짜와 제목으로 구성하면 관리하기 편하다.

posts/
  guide-001-github-pages.html
  guide-002-ai-agent-intro.html
  report-001-paper-review.html

포스트 HTML은 index.html과 같은 헤더·푸터를 공유하고, CSS는 ../style.css로 상위 폴더를 참조한다.

Step 5 — 이미지 넣기

블로그의 핵심은 이미지다. 캐릭터 이미지, 인포그래픽, 스크린샷을 넣으면 글이 살아난다.

캐릭터 이미지

캐릭터 이미지는 assets/character/에 넣고 각 포스트에서 불러온다. 헤더 로고, 글쓴이 아바타, 히어로 이미지로 활용한다.

<!-- 헤더 로고 -->
<img src="../assets/character/waving.png" class="logo-icon">

<!-- 글 속 캐릭터 -->
<img src="../assets/character/laptop.png"
     alt="노트북을 든 캐릭터"
     style="max-width:300px;">

인포그래픽 이미지

인포그래픽은 글의 핵심 내용을 시각적으로 요약한다. AI 이미지 생성 도구(Codex, Midjourney, Canva 등)로 만들어도 되고, 직접 그려도 된다.

이미지를 assets/에 넣고 포스트 안에서 이렇게 참조한다.

<img src="../assets/guide-001-infographic.png"
     alt="GitHub Pages 설정 과정 인포그래픽">
이미지 파일 크기는 1MB 이하로 유지하는 게 좋다. PNG는 압축률이 낮으므로 JPEG나 WebP를 쓰면 더 빠르다.

Step 6 — Push하면 끝

파일을 다 만들었으면 push한다.

git add .
git commit -m "첫 포스트 추가"
git push origin main

30초~1분 후에 https://username.github.io/my-blog/에서 바뀐 내용이 반영된다. 그게 전부다.

핵심 정리

  • 무료다. 서버 비용 없음.
  • .nojekyll 파일로 순수 HTML 사용을 명시한다.
  • index.html이 메인 페이지, posts/에 글을 쌓는다.
  • 이미지는 assets/에 넣고 상대 경로(../assets/)로 참조한다.
  • push하면 자동 배포된다. CI/CD 설정 불필요.

이 블로그 자체가 이 방법으로 만들어졌다. 소스코드는 GitHub에서 볼 수 있다.
