# AAA Starter Kit 간단 사용법

> Obsidian에 팀원이 기록하면 → Claude Code가 분석하고 → 공개 사이트로 자동 배포

---

## 전체 흐름

```
멤버 (Obsidian 작성)
  ↓ obsidian-git 자동 push
GitHub vault 레포 (원본, 비공개 포함)
  ↓ /publish
GitHub site 레포 (Astro)
  ↓ 자동 빌드
공개 홈페이지 (Vercel / GitHub Pages)
```

---

## 시작하기 (30분)

### 1. 템플릿 복사

```bash
cp -r template ~/github/내팀이름-vault
cd ~/github/내팀이름-vault
git init && gh repo create 내팀이름-vault --private --source=. --remote=origin
git push -u origin main
```

### 2. Obsidian에서 열기

1. Obsidian → **Open folder as vault** → 위 폴더 선택
2. Community plugins → **obsidian-git** 설치
   - 자동 커밋 간격: 15분
   - 자동 push: 켜기

### 3. 팀 정보 채우기 (3개 파일)

| 파일 | 내용 |
|------|------|
| `99_meta/멤버목록.md` | 닉네임, GitHub ID, 역할 |
| `CLAUDE.md` (vault 루트 생성) | 팀 이름, 슬로건, 커밋 규칙 |
| `00_missions/Week_01_submit/` | 멤버별 `Week_01_{닉네임}_submit.md` |

### 4. 매주 운영자가 실행

```
/analyze 1    ← 1주차 분석 리포트 자동 생성
/publish      ← 공개 사이트 배포 (선택)
```

---

## 슬래시 명령어

| 명령어 | 하는 일 |
|--------|---------|
| `/analyze N` | N주차 분석 리포트 + 멤버 프로필 + 스킬 제안 자동 생성 |
| `/ln N` | N주차 LinkedIn 초안 생성 |
| `/archive` | 아카이브 북 갱신 |
| `/publish` | 공개 폴더만 site 레포로 sync → 배포 |

> Claude Code를 vault 루트 디렉토리에서 실행해야 명령어가 보입니다.

## 자주 막히는 곳

**슬래시 명령어가 안 보일 때**
→ vault 루트에 `.claude/commands/*.md` 있는지 확인, Claude Code를 vault 루트에서 실행

**obsidian-git이 push 안 될 때**
→ SSH key 또는 Personal Access Token 설정 필요 (Settings → Obsidian Git → Authentication)

**`/publish`가 sync-content.sh를 못 찾을 때**
→ vault와 site 레포가 형제 디렉토리인지 확인
```
~/github/
  ├── 내팀이름-vault/
  └── 내팀이름-site/
```
