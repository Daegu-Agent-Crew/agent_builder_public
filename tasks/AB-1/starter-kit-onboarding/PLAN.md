# PLAN — Starter Kit 온보딩 가이드

## 실행 계획

### Step 1: 기존 문서 분석 및 구조화
- **담당**: 대구루
- **입력**: starter-kit/간단사용법.md
- **출력**: 단계별 체크리스트 초안
- **세부**:
  - 전체 흐름(멤버 작성 → git push → 분석 → 배포) 정리
  - 30분 세팅 가이드를 번호 단계로 분해
  - 슬래시 명령어 표 / 공개·비공개 폴더 표 보존

### Step 2: 트러블슈팅 보강
- **담당**: 대구루
- **입력**: 기존 "자주 막히는 곳" 섹션
- **출력**: 확장된 트러블슈팅 가이드
- **세부**:
  - 슬래시 명령어 미인식, obsidian-git push 실패, sync-content.sh 경로 문제
  - 각 항목별 해결 방법 + 확인 포인트

### Step 3: README에서 링크 연결
- **담당**: 대구루
- **입력**: 루트 README.md
- **출력**: tasks/AB-1로의 링크 추가
- **세부**:
  - README의 Starter Kit 섹션에 태스크 링크 추가

## 의존성
- 기존 starter-kit/ 폴더 내용

## 리스크
- 기존 문서와 중복되지 않도록 링크 중심으로 구성
