# GOAL — Starter Kit 온보딩 가이드

## 목표
기존 starter-kit 문서를 태스크 형태로 재구성하여, 신규 팀원이 30분 이내에 Obsidian + Claude Code 환경을 세팅할 수 있도록 한다.

## 성공 기준 (Definition of Done)
- [ ] starter-kit 간단사용법.md 내용이 태스크 형태로 재구성된다
- [ ] 단계별 체크리스트가 제공된다
- [ ] 자주 발생하는 문제(Troubleshooting)가 정리된다
- [ ] 기존 starter-kit/ 폴더 문서와 링크가 연결된다

## 범위
### 포함 (In Scope)
- 기존 starter-kit/간단사용법.md 내용 재구성
- 온보딩 단계별 체크리스트
- 트러블슈팅 가이드

### 제외 (Out of Scope)
- starter-kit 자체의 기능 변경
- 새로운 슬래시 명령어 추가
