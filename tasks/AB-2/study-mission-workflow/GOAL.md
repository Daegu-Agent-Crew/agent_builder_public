# GOAL — 스터디 미션 워크플로우 정의

## 목표
주간 스터디 미션의 전체 라이프사이클(출제 → 제출 → 분석 → 피드백)을 태스크 기반으로 정의하여, 커뮤니티 멤버가 일관된 방식으로 미션에 참여할 수 있도록 한다.

## 성공 기준 (Definition of Done)
- [ ] 미션 = 태스크 매핑 규칙이 문서화된다 (AB-N → Week N)
- [ ] 미션 제출 템플릿이 제공된다
- [ ] /analyze 결과가 자동으로 태스크 STATUS에 반영되는 흐름이 정의된다
- [ ] 미션 완료 → 위키 등록 파이프라인이 명세된다

## 범위
### 포함 (In Scope)
- 미션 출제/제출/분석 워크플로우 정의
- 미션 템플릿 (Obsidian 호환)
- team-memory 연동 지점 설계 (Phase 2에서 구현)

### 제외 (Out of Scope)
- 실제 미션 콘텐츠 작성
- 자동화 스크립트 구현 (별도 태스크)
